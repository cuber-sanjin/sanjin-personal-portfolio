## 项目说明

叁金（Sanjin）是一个面向日常工作与研究任务的通用智能体平台。用户不需要先理解工具或工作流，只要从自然语言开始，系统便会根据任务切换合适的 Agent：查资料时联网搜索，问内部文件时走 RAG，需要交付物时进入 PPT 状态机，复杂问题则交给可反思的深度研究引擎。

## 技术架构

```text
浏览器工作台（原生 HTML / CSS / JavaScript）
  ├─ REST：会话、文件与 PPT 实例管理
  └─ SSE：统一 AgentStreamEvent（thinking / text / reference / recommend / complete）
                         │
Spring Boot + Java 21 + Spring AI
  ├─ BaseAgent：ChatMemory、上下文压缩、任务生命周期
  ├─ WebSearch / File / Skills：ReAct + MCP 工具回调
  ├─ Deep Research：Plan-Execute + 多轮 Critique + 并发控制
  └─ PPT Builder：State Machine + 模板 Schema + 断点恢复
                         │
MySQL（会话与元数据） · PostgreSQL + PgVector（RAG）
MinIO（文件与生成物） · Redis / Redisson（缓存与任务协调）
```
